# onlytor
Это Docker-песочница, где весь трафик worker-контейнера обёрнут в Tor через tun2socks.

## Быстрый старт
Требования - docker, docker compose, git, хост на линуксе.
```bash
git clone https://github.com/TamerLAN42/onlytor.git
cd onlytor
docker compose up -d
```
В некоторых регионах может потребоваться прописать мосты в [/tor/torrc](/tor/torrc)

Затем - 
```bash 
docker exec -it torw sh
curl https://check.torproject.org/api/ip
```
Если `"IsTor":true`, а вернувшийся айпи вам незнаком - поздравляю, вы в сети.

## Архитектура
Вся магия творится в двух контейнерах:
- `tor` - Соединяет нас с сетью тор и обеспечивает socks5-прокси на порту 9050, а также обслуживает днс-запросы на 53 порту.
  - Содержит proxychains, curl и nano для отладки.
  - При старте проверяет свою готовность, делая запросы к api torproject
- `worker` - Оборачивает весь свой трафик в socks5-прокси соседнего контейнера.
  - Содержит базовый набор инструментов для анализа, всегда можно добавить больше ;)
  - Перед стартом ждёт готовности tor-контейнера, не поднимется, пока нет подключения к сети тор. 
  - Все DNS-запросы идут через DNSPort tor'а.

## Ограничения
- Тор не умеет проксировать UDP, за исключением DNS-запросов. Proxychains в `tor` пропустит UDP напрямую, допустив утечку, а UDP-трафик в `worker` будет дропаться.
- Диапазон адресов докер-подсети фиксированный - `172.21.0.0/24`. Если он у вас уже занят - поменяйте на свободный в [/docker-compose.yml](/docker-compose.yml), замените диапазон подсети и фиксированные адреса контейнеров.
- Транспортный плагин только obfs4/lyrebird, всё остальное устанавливается ручками самостоятельно.
